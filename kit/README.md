# kit — 카드뉴스·릴스 제작 양식

매주 카드뉴스 7개·릴스 7편을 만드는 데 필요한 규칙, 스크립트, 시나리오를 이 폴더에 모아 둔다.
0315 미디어(`content/RUNBOOK.md`)처럼 **저장소 안의 RUNBOOK만 읽고 만들 수 있게** 하는 것이 목적.

| 경로 | 내용 |
| --- | --- |
| `card/RUNBOOK.md` | 카드뉴스 규칙·순서·사용한 주제 |
| `card/make_posts.py` | 카드 이미지 생성기 (1080×1350, navy/paper) |
| `card/posts.example.json` | posts.json 작성 예시 |
| `reels/RUNBOOK.md` | 릴스 규칙·순서·시나리오 형식·사용한 주제 |
| `reels/rec/` | 녹화·음성·합성 스크립트 |
| `reels/scn/` | 검증된 시나리오 14편 (1~2주차) |

발행 자체(`docs/posts/…` → 인스타)는 저장소 루트 `README.md` 참고.
